# Cat Treasure Hunt 🎮

A Scratch game where the player controls a cat, collects gems, avoids a ghost, and unlocks a treasure.

## Features

* Arrow-key player movement
* Gem collection and score tracking
* Ghost enemy and lives system
* Treasure unlock condition
* Game-over and winning messages

## Technologies

* Scratch 3.0

## How to Play

1. Open the `.sb3` file in [Scratch](https://scratch.mit.edu/).
2. Use the arrow keys to move the cat.
3. Collect gems and avoid the ghost.
4. Collect enough gems to unlock the treasure.
